# `@agentixdev/adapters-http`

Explicit Web `Request`/`Response` routes and an optional thin Node HTTP host for
[Agentix](https://pewpewgogo.github.io/agentix/) applications.

```sh
npm install @agentixdev/core @agentixdev/adapters-http
```

Import `@agentixdev/adapters-http/web` for Web-standard handlers or
`@agentixdev/adapters-http/node` for the Node host. Agentix is research-stage,
ESM-only, and pre-1.0. See the
[HTTP guide](https://pewpewgogo.github.io/agentix/HTTP.html).
